# Repositório F-Droid de lamggm

Repositório oficial para distribuir os aplicativos Android publicados por
`lamggm`.

## Adicionar no F-Droid

Use esta URL no gerenciador de repositórios do F-Droid:

```text
https://lamggm.github.io/fdroid/repo
```

O índice e os APKs são assinados. Confira o fingerprint mostrado na página
principal antes de confiar no repositório.

## Aplicativos

- **Banco de Horas** — marcações de ponto locais com sincronização opcional.

## Segurança

Os keystores, senhas e o `config.yml` real são mantidos fora deste repositório.
Somente índices assinados, metadados públicos e APKs release são publicados.
